# AutoParts Hub — курсовая работа

Интернет-магазин автозапчастей. Предмет: «Распределенные системы обработки данных».

Правообладатель проекта: `ignil722`. Уведомление о правах — в `COPYRIGHT.md`.

Учебный интернет-магазин автозапчастей на Django 5: каталог, избранное, корзина, демонстрационная оплата, управление заказами, складской журнал и отчёты Excel/PDF.

## Быстрый запуск

Требуется Python 3.11+.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`.

## Запуск в PyCharm

1. Откройте папку проекта, содержащую `manage.py` и `requirements.txt`.
2. В `Settings → Project → Python Interpreter` выберите существующий интерпретатор `.venv/Scripts/python.exe`.
3. В терминале PyCharm выполните `run.bat` или выберите готовую конфигурацию `AutoParts Hub` в верхней панели и нажмите Run.

`run.bat` автоматически применяет миграции, создаёт/обновляет демонстрационные данные и запускает сервер на `http://127.0.0.1:8000/`.

Демонстрационные пользователи создаются командой `seed_demo` только для учебного запуска:

- администратор: `admin` / `Admin123!`;
- покупатель: `buyer` / `Buyer123!`.

## Тестовая оплата

- `4242 4242 4242 4242` — успешная операция;
- `4000 0000 0000 0002` — отказ банка;
- срок действия должен быть в будущем, CVV — любые три цифры.

Реальная платёжная система не подключена, полные данные карты не сохраняются.

## База и email

Без переменных окружения используется SQLite и консольная отправка email. Для PostgreSQL задайте `DATABASE_URL`, например `postgresql://user:password@host:5432/database`. SMTP и остальные параметры перечислены в `.env.example`; в Replit они задаются через Secrets.

## Полезные команды

```powershell
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
python manage.py collectstatic --noinput
```

Административный интерфейс магазина доступен по `/staff/`, резервный Django admin — по `/django-admin/`.

## Публикация на Render

В корне проекта находятся `render.yaml` и `build.sh`. После отправки проекта в
GitHub выберите в Render `New → Blueprint`, подключите репозиторий и примените
Blueprint. При создании Render попросит значение `DEMO_ADMIN_PASSWORD` — укажите
отдельный сложный пароль, который не хранится в GitHub. PostgreSQL, миграции,
демонстрационные данные и запуск Gunicorn будут настроены автоматически.

Репозиторий для публикации: `ignil722/kursovaya-avtozapchasti`, ветка `main`.
Версия Python закреплена в `.python-version`. Веб-сервис и база размещаются
в одном регионе Frankfurt; Render выдаёт публичную HTTPS-ссылку после успешного
развёртывания. Каталог, аккаунты, корзина, заказы и панель `/staff/` доступны
через один адрес.

Бесплатный веб-сервис засыпает после 15 минут без запросов, поэтому первое
открытие после простоя может занять около минуты. Бесплатная база PostgreSQL
действует 30 дней. Для дальнейшей работы потребуется платная база или другой
постоянный PostgreSQL: https://render.com/docs/free.

Файлы демонстрационных товаров входят в репозиторий. Новые загруженные через
админ-панель файлы на бесплатном экземпляре Render не являются постоянными;
для постоянных пользовательских загрузок нужен persistent disk либо облачное
объектное хранилище.

## Структура

- `accounts/` — пользователь и роли;
- `catalog/` — товары, категории, производители, избранное и склад;
- `orders/` — корзина, заказы, оплата, статусы и email;
- `reports/` — сводные данные, Excel и PDF;
- `templates/`, `static/` — адаптивный Bootstrap 5 интерфейс;
- `docs/spec.md` — требования и принятые правила.

Каталоги `artifacts/`, `lib/` и `scripts/` содержат исходный дизайн-прототип и не участвуют в запуске Django-приложения.
