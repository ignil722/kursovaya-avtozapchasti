# AutoParts Hub — спецификация

## Назначение

Распределённая информационная система на Django для автоматизации интернет-магазина автозапчастей. Интерфейс русскоязычный, адаптивный, валюта — рубли.

## Роли

- **Покупатель**: публичный каталог, после входа — избранное, корзина, checkout, тестовая оплата и только собственные заказы.
- **Администратор**: полный CRUD категорий, производителей и товаров; складские корректировки; все заказы и статусы; Excel/PDF-отчёты.

Регистрация создаёт только покупателя. Администратор создаётся через superuser, Django admin или `seed_demo`.

## Данные

- `User` с ролью `admin/buyer` и обязательным уникальным email.
- `Category`, `Manufacturer`, `Product` с уникальным SKU, ценой, остатком, описанием и опциональным изображением.
- `StockMovement` — полный журнал начального остатка, корректировок, резервов и возвратов.
- `Wishlist`, `Cart`, `CartItem` привязаны к конкретному пользователю.
- `Order`, `OrderItem` сохраняют snapshot названия, артикула и цены.
- `PaymentAttempt` хранит только результат и последние четыре цифры тестовой карты.

## Бизнес-правила

- Каталог фильтруется по строке поиска, категории, производителю, цене; поддерживает сортировку и страницы.
- Checkout в транзакции блокирует товары, повторно проверяет остаток, создаёт заказ и складские движения. Количество или остаток не могут быть отрицательными.
- Статусы: `created → paid → delivered`; `created/paid → cancelled`. Отмена возвращает товар один раз.
- `4242 4242 4242 4242` имитирует успех, `4000 0000 0000 0002` — отказ. Реальные карты не принимаются.
- `post_save(Order)` планирует email после успешного commit транзакции.

## Отчёты

Для периода продаж и даты остатков формируются HTML, Excel и PDF:

1. перечень и количество проданных товаров;
2. остатки на выбранную дату по сумме складских движений;
3. самые популярные товары;
4. самые невостребованные товары, включая позиции с нулём продаж.

Продажами считаются только `paid` и `delivered` заказы по `paid_at`. PDF использует кириллический TrueType-шрифт, Excel содержит отдельные форматированные листы.

## Среда

- Python 3.11+, Django 5.x;
- SQLite по умолчанию, PostgreSQL при наличии `DATABASE_URL`;
- Bootstrap 5, HTML5 и JavaScript client validation, Django Forms server validation;
- `openpyxl`, `reportlab`, Django signals/email;
- secrets и SMTP-пароли не хранятся в Git.
